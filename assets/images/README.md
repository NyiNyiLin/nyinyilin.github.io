# Image folders

The full-screen landing image is stored in `hero/` as `hero-background.webp`. Event-specific photos can be placed in the matching folder under `events/`.

Recommended hero filenames: `hero-01.webp` through `hero-05.webp`.

The five existing race photographs are stored in `highlights/` and displayed in the “Race day moments” section. The hero uses its own optimized copy so it can be replaced independently later.
